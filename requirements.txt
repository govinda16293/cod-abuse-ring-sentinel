# What the DEPLOYED Streamlit app needs, and nothing else.
#
# Streamlit Community Cloud installs this file and currently runs Python 3.14.7.
# The exact pins that produced the reported metrics have no cp314 wheels, so
# pinning them here makes the build fall back to source and fail on pyarrow and
# pandas. Those pins live in requirements-pipeline.txt and are still what the
# metrics were produced with.
#
# Floors rather than pins, so the resolver picks a wheel for whatever Python the
# host runs. The app only reads precomputed artifacts, so the modelling stack is
# deliberately absent: no scikit-learn, lightgbm, shap, matplotlib or scipy.
# shap and anthropic are lazy imports inside functions the hosted app never
# reaches, so leaving them out does not break the explanation panel; the LLM
# button falls back to the deterministic template writer.
streamlit>=1.39,<2
pandas>=2.2,<4
numpy>=2.0,<3
pyarrow>=20
